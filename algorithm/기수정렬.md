### 기수정렬이란?
- 낮은 자리수부터 비교하여 정렬해 간다는 것을 기본 개념으로 하는 정렬 알고리즘
- 기수정렬은 비교 연산을 하지 않으며 정렬 속도가 빠르다.
- 데이터 전체 크기에 기수 테이블의 크기만한 메모리가 더 필요함

### 알고리즘
1. 데이터 전체 크기에 기수 테이블의 크기만한 배열 생성
2. 1의 자리수 ~ 가장 큰 자리수 까지 기수들을 기준으로 배열에다가 집어넣음

### 예시
1. 초깃값: [15,27,64,25,50,17,39,28]
2. 1의 자리수를 기준으로 정렬
   [0: {50} 1: {} 2: {} 3: {} 4: {64} 5: {15,25} 6: {} 7: {27,17} 8: {28} 9:{39}]
3. 2의 자리수를 기준으로 정렬
   [0: {} 1: {15,17} 2: {25,27,28} 3: {39} 4: {} 5: {50} 6: {64} 7: {} 8: {} 9: {}]
4. 결과 : [15,17,25,27,28,39,50,64]

### 알고리즘
```java
void radix_sort(int[] arr){
    Queue<Integer[]> queueArr = new Queue[10];
    for(int i=0;i<queueArr.length;i++){
        queueArr[i] = new LinkedList<>();
    }
    
    int maxLen = getMaxLen(arr);
    
    int div = 1;
    int idx = 0;
    for(int i=0;i<maxLen;i++){
        for(int j=0;j<arr.lenth;j++){
            queueArr[(arr[j]/div)%10].add(arr[j]);
        }
        
        for(int j=0;j<queueArr.length;j++){
            while(!queueArr[j].isEmpty()){
                arr[idx++]=queueArr[j].poll();
            }
        }
        div*=10;
        idx=0;
    }
}

int getMaxLen(int[] arr){
    int maxLen = 0;
    for(int i=0;i<arr.length;i++){
        int len = (int) Math.log10(arr[i])+1;
        if(maxLen < len){
            maxLen = len;
        }
    }
    return maxLen;
}
```
### 시간복잡도
- 최선, 최악의 경우 모두 O(d*(k+n))
- d는 기수의 크기, k는 기수의 도메인 크기

### 공간복잡도
- O(k+n) 
- k: 기수의 도메인 크기

### 장점
- O(d*(k+n))으로 속도가 빠르다
- 안정정렬이다.

### 단점
- 추가적인 메모리 필요
- 정렬 방법의 특수성 때문에, 일부 특수한 비교 연산이 필요한 데이터에는 적용할 수 없을 수 있다.
