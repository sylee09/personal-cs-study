### 병합 정렬이란?
- 비교 기반 정렬 알고리즘이다.
- 안정 정렬에 속하며, 분할 정복 알고리즘의 하나이다.
- 분할 정복 : 큰 문제를 작은 문제 단위로 쪼개면서 해결해나가는 방식

### 알고리즘
1. 정렬되지 않은 리스트를 각각 하나의 원소만 포함하는 n개의 부분리스트로 분할
   (한 원소만 든 리스트는 정렬된 것과 같으므로)
2. 부분리스트가 하나만 남을 때까지 반복해서 병합하며 정렬된 부분리스트를 생성한다. 마지막 남은 부분리스트가 정렬된 리스트다.
- 흔히 쓰이는 하향식 2-way 합병 정렬은 아래와 같이 작동
  1. 리스트의 길이가 1이하면 이미 정렬된 것으로 본다. 그렇지 않은 경우에는
  2. 분할: 정렬되지 않은 리스트를 절반으로 잘라 비슷한 크기의 두 부분 리스트로 나눈다.
  3. 정복: 각 부분 리스트를 재귀적으로 합병 정렬을 이용해 정렬한다.
  4. 결합: 두 부분 리스트를 다시 하나의 정렬된 리스트로 합병한다. 이때 정렬 결과가 임시배열에 저장된다.
  5. 복사: 임시 배열에 저장된 결과를 원래 배열에 복사한다.

### 예시
1. 초깃값: [7,2,0,1,5,6,4]을 [7,2,0,1] [5,6,4] 로 나눈다.
- [7,2,0,1] => [7,2] [0,1] => [7] [2] [0] [1] 로 나뉘어짐
- [5,6,4] => [5,6] [4] => [5] [6] [4]로 나뉘어짐
2. [7] [2]를 정렬하면 [2,7]이 되고 [0] [1]을 정렬하면 [0,1]이 됨
- [2,7] [0,1]을 정렬하면 [0,1,2,7]이됨
3. [5] [6] 을 정렬하면 [5,6]이 되고 [4]는 이미 정렬되어 있다.
- [5,6] [4] 를 정렬하면 [4,5,6] 이 됨
4. [0,1,2,7] [4,5,6]을 정렬하면 [0,1,2,4,5,6,7]이 된다.

### 알고리즘
```java
    public void mergeSort(int[] array, int left, int right) {
  if (left < right) {
    int mid = (left + right) / 2;

    mergeSort(array, left, mid);
    mergeSort(array, mid + 1, right);
    merge(array, left, mid, right);
  }
}

public void merge(int[] array, int left, int mid, int right) {
  int[] L = Arrays.copyOfRange(array, left, mid + 1);
  int[] R = Arrays.copyOfRange(array, mid + 1, right + 1);

  int i = 0, j = 0, k = left;
  int ll = L.length, rl = R.length;

  while (i < ll && j < rl) {
    if (L[i] <= R[j]) {
      array[k] = L[i++];
    } else {
      array[k] = R[j++];
    }
    k++;
  }

  while (i < ll) {
    array[k++] = L[i++];
  }
  while (j < rl) {
    array[k++] = R[j++];
  }
}
```

### 시간복잡도
- 최선, 최악의 경우 모두 O(nlgn)

### 공간복잡도
- 배열 복사가 필요하므로 O(N)

### 장점
- O(nlgn)으로 속도가 빠르다
- 안정 정렬이다.

### 단점
- 배열 복사에 필요한 추가적인 메모리가 필요하다.

### 퀵정렬과 비교
- 머지 소트가 최악, 최선의 경우 O(nlgn)이지만 퀵소트가 평균적인 경우 더 빠른 이유:
  - 퀵 소트는 캐시 메모리를 최대한 활용하고 추가적인 메모리를 사용하지 않아 복사 과정이 필요하지 않음
  - 퀵 소트는 배열의 데이터를 연속적인 메모리 블록 내에서 교환하며 정렬하여 CPU가 한 번에 많은 양의 데이터를 캐시 메모리로 가져온 후,
  해당 캐시 내에서 모든 필요한 연산을 완료할 수 있게함 (참조 지역성)
  - 머지 소트는 데이터를 두 개의 작은 배열로 나눈 다음 정렬하고 다시 병합함. 이 과정에서 데이터를 새로운 메모리 공간에 할당하고 복사하는 작업이 필요.
  이러한 비연속적인 메모리 접근은 캐시 미스를 자주 유발하여 CPU가 메인 메모리에서 데이터를 다시 가져와야 하므로 속도가 느려짐.
