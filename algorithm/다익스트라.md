### 다익스트라 알고리즘이란?
- 다이나믹 프로그래밍을 활용한 최단 경로 탐색 알고리즘
- 특정한 하나의 정점에서 다른 모든 정점으로 가는 최단 경로를 알려줌
- 음의 간선을 포함할 수는 없다.
- 최단 거리는 여러 개의 최단 거리로 이루어져 있으므로 다이나믹 프로그래밍 문제

### 알고리즘
1. 출발 노드를 설정
2. 출발 노드를 기준으로 각 노드의 최소 비용을 저장
3. 방문하지 않은 노드 중에서 가장 비용이 적은 노드를 선택
4. 해당 노드를 거쳐서 특정한 노드로 가는 경우를 고려하여 최소 비용을 갱신
5. 위 과정에서 3번 ~ 4번을 반복

### 구현
1. 순차 탐색
- 방문하지 않은 노드 중 거리값이 가장 작은 노드를 선택해 다음 탐색 노드로 삼는다. 그 노드를 찾는 방식이 순차 탐색이 된다.
즉 거리 테이블의 앞에서부터 찾아내야 하므로 노드의 개수만큼 순차 탐색을 수행해야 한다. 따라서 노드 개수가 N이라고 할 때 각 노드마다 
최소 거리값을 갖는 노드를 선택해야 하는 순차 탐색이 수행되므로 (N - 1) * N = O(N^2)의 시간이 걸린다.
```java
int findSmallestNode(){
    int min_dist = Integer.MAX_VALUE;
    int min_idx = -1;
    for (int i = 0; i <= N; i++) {
        if (visited[i]) {
            continue;
        }
        if (dist[i] < min_dist) {
            min_dist = dist[i];
            min_idx = i;
        }
    }
    return min_idx;
}

void dijkstra() {
    for (int i = 1; i <= N; i++) {
        dist[i] = map[start][i];
    }
    dist[start]=0;
    visited[start]=true;

    for (int i = 0; i < N - 1; i++) {
        int new_node = FindSmallestNode();
        visited[new_node] = true;

        for (int j = 0; j <= N; j++) {
            if(visited[j]){
                continue;
            }
            if (dist[j] > dist[new_node] + map[new_node][j]) {
                dist[j] = dist[new_node] + map[new_node][j];
            }
        }
    }
}
```
2. 우선순위 큐
- 자바의 PriorityQueue를 이용해서 구현하고 순차 탐색을 사용할 경우 노드 개수에 따라 탐색 시간이 매우 오래 걸릴 수 있는 문제를 해결하기 위해 도입되기도 함
- 정렬기준은 최단거리를 기준으로 정렬
- 우선순위 큐를 사용하면 방문 여부를 기록할 배열은 없어도 됨
  - 우선순위큐가 알아서 최단 거리의 노드를 앞으로 정렬하므로 기존 최단 거리보다 크다면 무시하면 됨
  - 만약 기존 최단거리보다 더 작은 값을 가지는 노드가 있다면 그 노드와 거리를 우선순위 큐에 넣는다.

```java
// graph = HashMap<Integer,ArrayList<int[]>>()
// ArrayList안에는 [이웃 노드, 거리]가 들어감
void dijkstra() {
    PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> {
        if (a[1] < b[1]) {
            return -1;
        } else if (a[1] > b[1]) {
            return 1;
        }
        return 0;
    });
    pq.offer(new int[]{start, 0});

    while (!pq.isEmpty()) {
        int[] cur = pq.poll();
        if (dist[cur[0]] > cur[1]) {
            dist[cur[0]] = cur[1];
        }

        for (int[] neighbor : graph.get(cur[0])) {
            if (cur[1] + neighbor[1] < dist[neighbor[0]]) {
                pq.offer(new int[]{neighbor[0], cur[1] + neighbor[1]});
            }
        }
    }
    
}
```

### 우선순위 큐의 경우 시간 복잡도
- 간선의 수를 E, 노드의 수를 V라고 했을때 O(ElgV)가 됨
- 모든 간선이 한번씩 검사된다는 점에서 첫 번째 작업이 O(E), 각 간선마다 우선순위 큐에 자료가 삽입 연산이 일어난다는 점에서 O(ElgE)
- 이 둘을 합쳤을 때, E+ElgE => O(ElgE)
  - V^2 > E이므로 O(lgE) = O(lgV) 따라서 O(ElgV)가 됨
