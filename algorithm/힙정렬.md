### 힙 정렬이란?
- 최대 힙 트리나 최소 힙 트리를 구성해 정렬을 하는 방법으로서, 내림차순 정렬을 위해서는 최소 힙을 구성하고 오름차순 정렬을 위해서는 최대 힙을 구성하면 된다.

### 알고리즘
1. n개의 노드에 대한 완전 이진 트리를 구성한다.
이때 루트 노드부터 부모노드, 왼쪽 자식노드, 오른쪽 자식노드 순으로 구성한다.
2. 최대 힙을 구성한다. 최대 힙이란 부모노드가 자식노드보다 큰 트리를 말하는데, 단말 노드를 자식노드로 가진 부모노드부터 구성하며 아래부터 루트까지 올라오며
순차적으로 만들어 갈 수 있다.
3. 가장 큰 수(루트에 위치)를 가장 작은 수와 교환한다.
4. 2와 3을 반복한다.

### 완전 이진 트리
- 마지막 레벨을 제외하고 모든 레벨이 완전히 채워져 있으며, 마지막 레벨의 모든 노드는 가능한 한 가장 왼쪽에 있다.
- 마지막 레벨 h에서 1 부터 2^h-1개의 노드를 가질 수 있다.

### 예시
1. 초깃값: [7,2,0,1,5,6,4] 
2. 1번째 heapify후 [7,5,6,1,2,0,4]
3. 7과 4를 교환후 heapify => [4,5,6,1,2,0,7] => heapify 후 : [6,5,4,1,2,0,7]
4. 6과 0을 교환후 heapify => [0,5,4,1,2,6,7] => heapify 후 : [5,2,4,1,0,6,7]
5. 5와 0을 교환후 heapify => [0,2,4,1,5,6,7] => heapify 후 : [4,2,0,1,5,6,7]
6. 4와 1을 교환후 heapify => [1,2,0,4,5,6,7] => heapify 후 : [2,1,0,4,5,6,7]
7. 2와 0을 교환후 heapify => [0,1,2,4,5,6,7] => heapify 후 : [1,0,2,4,5,6,7]
8. 1과 0을 교환후 heapify => [0,1,2,4,5,6,7] => heapify 후 : [0,1,2,4,5,6,7]
9. 정렬 완료

### 알고리즘
```java
public static void heapify(int array[], int n, int i) {
    int p = i;
    int l = i * 2 + 1;
    int r = i * 2 + 2;

    if (l < n && array[p] < array[l]) {
        p = l;
    }

    if (r < n && array[p] < array[r]) {
        p = r;
    }

    if (i != p) {
        swap(array, p, i);
        heapify(array, n, p);
    }
}

public static void heapSort(int[] array) {
    int n = array.length;

    // init, max heap
    for (int i = n / 2 - 1; i >= 0; i--) {
        heapify(array, n, i);
    }

    // for extract max element from heap
    for (int i = n - 1; i > 0; i--) {
        swap(array, 0, i);
        heapify(array, i, 0);
    }
}

public static void swap(int[] array, int a, int b) {
    int temp = array[a];
    array[a] = array[b];
    array[b] = temp;
}
```

### 시간복잡도
- 최선, 최악의 경우 모두 O(nlgn)

### 공간복잡도
- 배열 내에서만 이뤄지므로 O(1)

### 장점
- O(nlgn)으로 속도가 빠르다

### 단점
- 불안정 정렬이다.
- 퀵소트 보다 참조 지역성 측면에서 불리하다.
  - 퀵 정렬: 작은 연속된 영역내에서 집중적으로 비교와 교환이 일어나 캐시 효율이 매우 높다.
  - 힙 정렬: 힙의 속성을 유지하기 위해 노드와 자식 노드를 비교하는데, 이들이 배열내에서 멀리 떨어진 위치에 있을 수 있다.
  => 데이터를 가져오기 위해 캐시 미스가 발생할 확률이 높고, CPU의 효율이 떨어진다.
