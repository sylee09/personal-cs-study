### 컴퓨터의 구성
- 컴퓨터 시스템은 크게 하드웨어와 소프트웨어로 나누어짐

### 소프트웨어
- 하드웨어에 동작을 지시하고 제어하는 역할을 하는 프로그램과 프로그램에 필요한 데이터를 말함

### 하드웨어
- 중앙처리장치
  - 프로그램을 실행하고 입력된 데이터를 처리함
- 주기억장치
  - 실행 중인 프로그램과 프로그램 실행에 필요한 데이터를 일시적으로 저장
- 보조기억장치
  - 프로그램과 데이터를 영구히 저장
- 입출력장치
  - 중앙처리장치나 주기억장치에 데이터를 입력하거나 출력.
  - 입력장치에는 키보드, 마우스, 스케너 등이 있고 출력장치에는 모니터, 프린터 등이 있다.

### 중앙처리장치
- 프로그램 명령어를 해독하여 실행하는 일을 함.
- 제어장치, 연산장치, 레지스터 집합의 세 부분으로 구성됨
- 주기억장치를 비롯한 다른 장치들과는 버스로 연결됨
- 중앙처리장치는 인출 단계 -> 해독 단계 -> 실행 단계로 구성된 일련의 동작을 반복함으로서 명령어를 실행
  - 인출 단계 : 주기억장치에 저장된 명령어 하나를 읽어 옴
  - 해독 단계 : 읽어 온 명령어를 제어 정보로 해독
  - 실행 단계 : 해독된 명령을 실행

### 제어장치
프로그램 명령어를 해독하고, 해독된 명령의 의미에 따라 연산장치, 주기억장치, 입출력장치 등에 동작을 지시.

### 연산장치
제어장치의 지시에 따라 연산을 수행. 덧셈, 뺄셈, 곱셈, 나눗셈의 산술 연산뿐만 아니라 AND, OR, NOT, XOR 같은 논리 연산을 수행

### 레지스터
중앙처리장치에서 명령어를 실행하는 동안 필요한 정보를 저장하는 기억 장소로, 다양한 종류의 레지스터가 있다.

### 주기억장치
현재 실행 중인 프로그램과 프로그램 실행에 필요한 데이터를 일시적으로 저장.
전체 기억 공간은 바이트 단위로 분할되어 있으며 공간마다 주소가 할당되어 있다.
쓰기, 읽기 동작이 있다.
- 쓰기 
  - 주기억장치의 주소 50에 데이터 20을 쓰려면 중앙처리장치는 주소 버스에 50, 데이터 버스에 20을 전송하고, 제어 버스에 쓰기 제어 신호를 보냄.
- 읽기
  - 주기억장치 주소 60에 저장된 데이터를 읽으려면 중앙처리장치는 주소 버스에 60을 전송하고, 제어 버스에 읽기 제어 신호를 보냄. 그러면 주소 60에 저장된 데이터가 데이터 버스를 통해 중앙처리장치로 전송됨.

### 시스템 버스
1. 제어 버스 : 쓰기 또는 읽기 동작을 경정하는 제어 정보가 전송됨
2. 주소 버스 : 주기억장치의 주소가 전송됨
3. 데이터 버스 : 데이터가 전송됨
