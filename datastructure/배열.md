### 배열
배열은 연속된 메모리 공간에 순차적으로 저장된 데이터 모음
- 자바의 경우 동일 타입의 데이터를 저장함 (ex int[] 인트형 배열로 인트만 받음)
- 배열을 구성하는 각각의 값을 요소(element)라고 하며, 배열에서의 위치를 가리키는 숫자는 인덱스라고 함

### 배열 표현
```java
int[] a = new int[]{1,2,3,4,5,6,7,8,9};
```
a[0] = 1, a[1] = 2 , ... , a[8] = 9
- int의 크기는 4byte이고 인덱스 0 ~ 8까지의 4byte 크기의 인트형 정수들이 메모리에 연속하고 있다.

### 배열의 시간 복잡도
- read 
  - avg : O(1), worst : O(1)
- insert
  - 맨 처음 : O(N)
  - 맨 뒤 : O(1)
  - 중간 : O(N)
- delete
  - 맨 처음 : O(N)
  - 맨 뒤 : O(1)
  - 중간 : O(N)
- search
  - 맨 처음에 타겟이 있을때 : O(1)
  - 타겟을 인덱스로 하나하나 접근하면서 찾아야하므로 평균 : O(N)
